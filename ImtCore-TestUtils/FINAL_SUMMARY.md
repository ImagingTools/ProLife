## 📋 API пакета

Пакет экспортирует следующие функции:

### Взаимодействие со страницей
- `clickAt(page, x, y)` - Клик по координатам
- `clickOnElement(page, path)` - Клик по элементу через objectName
- `clickOnPage(page, pageId)` - Клик по странице меню
- `clickOnCommand(page, commandId)` - Клик по команде
- `clickOnButton(page, buttonPath)` - Клик по кнопке

### Работа с формами
- `fillTextInput(page, text, path)` - Заполнение текстового поля
- `selectComboBox(page, selectedText, path)` - Выбор из выпадающего списка

### Навигация и ожидание
- `reloadPage(page, url)` - Перезагрузка страницы
- `waitForPageStability(page, options)` - Ожидание стабильности DOM
- `delay(time)` - Задержка

### Скриншоты
- `checkScreenshot(page, filename, maskParams)` - Создание скриншота с маской

### Авторизация
- `login(page, username, password, options)` - Авторизация пользователя

### Прокрутка
- `wheelScroll(page, deltaY)` - Прокрутка колесом мыши

### Global Setup
- `createGlobalSetup(options)` - Фабрика для создания функции глобальной настройки

## 🚀 Что дальше?

### Для команды ImtCore
1. Скопировать содержимое `ImtCore-TestUtils/playwright-utils/` в `ImtCore/Tests/playwright-utils/`
2. Создать PR в репозитории ImtCore
3. После мерджа - опубликовать пакет (npm/git/file dependency)

Подробные инструкции: `ImtCore-TestUtils/INSTRUCTIONS_FOR_IMTCORE.md`

### Для команды ProLife
1. После публикации пакета в ImtCore:
   - Обновить `Tests/frontend/package.json` для использования `@imtcore/playwright-utils`
   - Обновить импорты во всех тестовых файлах
   - Удалить старый `utils.js`
   - Удалить директорию `ImtCore-TestUtils`

Подробное руководство: `ImtCore-TestUtils/MIGRATION_GUIDE.md`
