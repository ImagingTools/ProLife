# ImtCore Test Utils

Этот каталог содержит общие утилиты для тестирования, которые должны быть перенесены в репозиторий **ImtCore** для повторного использования в различных проектах ImagingTools.

## Структура

```
playwright-utils/
├── package.json          # Конфигурация npm пакета
├── index.js             # Главная точка входа
├── utils.js             # Основные утилиты для тестирования
├── global-setup.js      # Фабрика для создания global setup
└── README.md            # Документация по использованию
```

## Следующие шаги

1. **Перенос в ImtCore**: Содержимое директории `playwright-utils` должно быть перенесено в репозиторий ImtCore в подходящую директорию (например, `Tests/playwright-utils`).

2. **Публикация пакета**: После переноса в ImtCore, пакет должен быть опубликован (либо в npm registry, либо в приватный registry, либо использоваться через git dependencies).

3. **Обновление зависимостей**: После публикации, обновить `Tests/frontend/package.json` в ProLife для использования опубликованного пакета:
   ```json
   {
     "devDependencies": {
       "@imtcore/playwright-utils": "^1.0.0"
     }
   }
   ```

4. **Обновление импортов**: Заменить локальные импорты на импорты из пакета во всех тестовых файлах.

## Текущее состояние

На данный момент этот код является примером организации общих утилит. Код был извлечен из `Tests/frontend/tests/utils.js` и `Tests/frontend/global-setup.js` и организован как переиспользуемый npm модуль.

## Для разработчиков

Если вы вносите изменения в общие утилиты тестирования:

1. Внесите изменения в соответствующий репозиторий (ImtCore после переноса)
2. Обновите версию пакета
3. Опубликуйте новую версию
4. Обновите зависимости в проектах, использующих эти утилиты

## Связанные файлы в ProLife

После переноса, следующие файлы в ProLife должны быть обновлены:
- `Tests/frontend/package.json` - добавить зависимость на @imtcore/playwright-utils
- `Tests/frontend/global-setup.js` - использовать createGlobalSetup из пакета
- Все тестовые файлы в `Tests/frontend/tests/` - обновить импорты
- `Tests/frontend/tests/utils.js` - может быть удален после миграции
