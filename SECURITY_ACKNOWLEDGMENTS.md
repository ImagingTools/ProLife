# Security Researchers Hall of Fame

This page recognizes security researchers and contributors who have helped improve the security of ProLife through responsible vulnerability disclosure.

## How to Get Listed

If you report a valid security vulnerability following our [responsible disclosure policy](SECURITY.md), we will:

- Add your name to this Hall of Fame (with your permission)
- Credit you in security advisories
- Provide CVE co-authorship opportunities (where applicable)

## Recognition Categories

### 🏆 Critical Impact
For discovering and reporting critical vulnerabilities that could lead to:
- Remote code execution
- Authentication bypass
- Data breach
- Complete system compromise

### 🥇 High Impact
For discovering and reporting high-severity vulnerabilities:
- Privilege escalation
- SQL injection
- Cross-site scripting (XSS)
- Significant data exposure

### 🥈 Medium Impact
For discovering and reporting medium-severity vulnerabilities:
- Information disclosure
- Denial of service
- Security misconfiguration
- Session management issues

### 🥉 Low Impact
For discovering and reporting low-severity vulnerabilities:
- Minor information leaks
- UI/UX security improvements
- Documentation improvements
- Best practice recommendations

## Reporting Guidelines

To be eligible for recognition:

1. Follow our [responsible disclosure policy](SECURITY.md)
2. Report vulnerabilities to security@imagingtools.com
3. Allow us reasonable time to fix the issue before public disclosure
4. Do not exploit the vulnerability beyond what is necessary for proof-of-concept
5. Do not access, modify, or delete user data

## Out of Scope

The following are not eligible for recognition:
- Publicly known vulnerabilities
- Issues in third-party services not controlled by ImagingTools
- Social engineering attacks
- Physical attacks
- Denial of Service (DoS) attacks without security implications

## Thank You

We deeply appreciate the security research community's efforts in making ProLife more secure for all our users. Your contributions help protect healthcare data and improve patient care.
